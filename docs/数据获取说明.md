# 数据获取说明

本项目使用阿里云天池公开数据集 **UserBehavior**，由于数据文件较大，不包含在 Git 仓库中，请按以下步骤获取数据。

## 1. 下载数据集

访问天池数据集页面：
https://tianchi.aliyun.com/dataset/649

点击"下载"按钮，下载 `UserBehavior.csv.zip`，解压后得到 `UserBehavior.csv`。

> 注意：下载需要注册阿里云账号并登录，数据集免费。

## 2. 数据集字段说明

| 列名 | 说明 | 示例 |
|------|------|------|
| user_id | 用户ID | 1 |
| item_id | 商品ID | 2268318 |
| category_id | 商品类目ID | 4145813 |
| behavior_type | 行为类型 | pv（浏览）/ fav（收藏）/ cart（加购）/ buy（购买） |
| timestamp | 时间戳（秒） | 1511544070 |

- 原始数据没有表头，共 5 列，以逗号分隔
- 时间范围：2017-11-25 至 2017-12-03
- 全量数据约 1 亿条，本项目使用前 100 万条作为演示

## 3. 放置数据

将下载的 CSV 文件重命名为 `user_behavior_raw.csv`，放到项目的 `data/` 目录下：

```
data/
└── user_behavior_raw.csv
```

## 4. 生成清洗后数据和数据库

按顺序运行以下脚本：

```bash
# 第一步：数据清洗，生成 my_clean.csv
python src/01_clean_data.py

# 第二步：建表入库，生成 taobao.db
python src/02_load_to_db.py
```

运行完成后，`data/` 目录下会生成：
- `my_clean.csv` —— 清洗后的数据
- `taobao.db` —— SQLite 数据库文件

## 5. 验证数据

可以用 DBeaver 或 SQLite 命令行验证：

```sql
-- 查看总记录数（应该约 28 万条）
SELECT COUNT(*) FROM user_behavior;

-- 查看行为分布
SELECT behavior_type, COUNT(*) FROM user_behavior GROUP BY behavior_type;
```

## 注意事项

- 原始数据全量约 1 亿条，如果直接处理全量数据，建议使用 MySQL 或 Spark，SQLite 可能较慢
- 本项目的演示数据是前 100 万条，清洗后约 28 万条
- `data/` 目录已在 `.gitignore` 中排除，不会被上传到 GitHub
