# 项目技术说明

## 技术栈与工具

| 环节 | 技术 | 用途 |
|------|------|------|
| 数据清洗 | Python 3 + Pandas | 缺失值处理、去重、时间字段转换 |
| 数据存储 | SQLite | 轻量型数据库，支持标准SQL查询 |
| 数据分析 | SQL（CTE、窗口函数、条件聚合、多表连接） | PV/UV、漏斗、RFM等指标计算 |
| 数据可视化 | Matplotlib | 趋势图、漏斗图、饼图、柱状图 |
| 数据库管理 | DBeaver | 图形化查询与结果验证 |

## 项目流程

### 1. 数据获取
- 数据集来源：阿里云天池 UserBehavior 用户行为数据集
- 原始数据：约100万条记录，5个字段（user_id, item_id, category_id, behavior_type, timestamp）
- 时间范围：2017-11-25 至 2017-12-03（共9天）

### 2. 数据清洗（src/01_clean_data.py）
- 去除完全重复的记录
- 过滤用户ID或行为类型为空的记录
- 将Unix时间戳转换为标准日期和小时字段
- 过滤时间戳超出数据范围的异常记录
- 清洗结果：约28万条有效数据，覆盖约1万用户

### 3. 建表入库（src/02_load_to_db.py）
- 创建用户行为表，建立3个索引（user_id、behavior_type、timestamp）
- 将清洗后的数据写入SQLite数据库
- 验证数据完整性：SELECT COUNT(*) 确认记录数

### 4. SQL分析（sql/目录）
- **L1 基础查询**：PV/UV计算、行为分布、热门类目统计
- **L2 进阶查询**：转化漏斗、复购率、用户跳失率、多表连接
- **L3 窗口函数**：留存分析、RFM用户分层、组内TopN、累计计算

### 5. 可视化与报告（src/03_analysis_and_charts.py）
- 每日PV/UV趋势图
- 时段活跃分布图
- 转化漏斗图
- RFM用户分层饼图
- Top10购买类目柱状图
- 行为类型分布饼图

## 核心分析结论

### 用户活跃规律
- 活跃高峰：晚间20:00-23:00
- 人均浏览量：约26次/人

### 转化漏斗
| 环节 | 用户数 | 转化率 |
|------|--------|--------|
| 浏览 | 10,000 | - |
| 收藏/加购 | 5,526 | 55.3% |
| 购买 | 2,332 | 42.2% |

- 主要流失环节：浏览→收藏加购，建议优化商品详情页和加购引导

### 用户分层（RFM）
- 重要价值用户：34.3%
- 重要保持用户：15.7%
- 重要发展用户：15.7%
- 一般挽留用户：34.3%

## 运行方式

```bash
# 安装依赖
pip install -r requirements.txt

# 数据清洗
python src/01_clean_data.py

# 建表入库
python src/02_load_to_db.py

# 分析与可视化
python src/03_analysis_and_charts.py
```

运行后在 `output/` 目录查看6张可视化图表。
